# ServiceStep

Eén trede van de dienstenladder: Audit, Implementatie, Care & Development. Drie naast elkaar vormen `fl-ladder`.

**Wat je meegeeft:** nummer, kicker (Instap / Bouwen / Onderhoud), titel, één zin, drie opleverpunten, een meta-regel.

**Regels**
- **Geen prijzen.** De meta-regel noemt vorm ("vaste prijs", "maandelijks"), nooit een bedrag. Prijs volgt via het formulier of het gesprek.
- Alleen de instap (`fl-service--entry`) krijgt de `forge`-bovenrand en het oranje nummer; de rest `line-strong` en `ink-muted`.
- Opsommingstekens zijn kleine vierkante kaders in `forge`, als de tanden van het tandwiel.
- Mobiel: onder elkaar, verbonden door de forge line.
