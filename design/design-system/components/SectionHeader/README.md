# SectionHeader

De opening van elk hoofdstuk langs de forge line: kicker, titel, intro, met optioneel het hoofdstuknummer ernaast.

**Wat je meegeeft:** kicker (`Hoofdstuk 0X · Naam`), een titel van maximaal acht woorden, een intro van één à twee zinnen.

**Regels**
- Titel in `h2` (Saira 600, `ink`), intro in `lead`-maat en `ink-muted`, breedte maximaal `measure`.
- De kicker heeft een `forge`-streepje van 24 × 2px ervoor; de tekst zelf is `ink-muted`, zodat hij in beide thema's leesbaar is.
- Hoofdstuknummer `.fl-numeral`: `forge` in donker, `ink` in licht (oranje tekst op wit mag niet).
- Titels zijn zinnen, geen slogans: wat de bezoeker krijgt, niet hoe slim de techniek is.
