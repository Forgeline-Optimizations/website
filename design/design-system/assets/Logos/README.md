# Logos

Uit de huisstijl, alleen zwart (#111111), wit (#F2F0EC) of oranje (#FF8700). Elke SVG heeft één vaste inktkleur (geen currentColor): kies het bestand op kleur.

- `logo-stacked-on-orange.svg` — Primair merkbeeld: zwart op Smeedoranje vlak. OG-afbeelding, avatar, visitekaartje.
- `logo-stacked-black.svg` / `logo-stacked-white.svg` — Staand logo, zonder vlak.
- `logo-horizontal-white.svg` — Navigatie en footer van de donkere site. Minimaal 140px breed.
- `logo-horizontal-black.svg` — Idem op het lichte thema en in documenten.
- `icon-white.svg` / `icon-black.svg` / `icon-orange.svg` — Los tandwiel-icoon: favicon, kleine merktekens, minimaal 24px.

De horizontale versie is opgebouwd uit het icoon en het woordmerk van het staande logo, met de verhoudingen uit de huisstijlgids (woordmerk 0,47 × de icoonhoogte, verticaal gecentreerd, tussenruimte 0,15 × de icoonhoogte).
